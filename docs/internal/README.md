# Internal working papers

Not documentation. This is the project's own material: the research it
was designed from, the plans it was built to, and drafts that have not
been posted. It is kept in the repository because the ADRs (architecture
decision records) cite it and because the reasoning is worth more than
the conclusions, but a reader looking for how to *use* `usv` wants
[`../index.md`](../index.md) instead.

its gates.
